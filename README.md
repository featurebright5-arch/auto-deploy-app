# 🚀 Auto Deploy App

Приложение для автоматического деплоя на Railway.

## Быстрый старт

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new/template?template=https://github.com/YOUR_USERNAME/auto-deploy-app)

## Локальный запуск

```bash
pip install -r requirements.txt
python app.py
```

## API Endpoints

- `GET /` - Главная страница
- `GET /health` - Проверка здоровья
- `GET /api/status` - Статус приложения
